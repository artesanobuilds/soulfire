# Current — soundscape exploration

Status: local prototype implemented after subsequent user approval, 2026-10-27. The research/design documents preserve the exploration history; see [implementation and validation](implementation.md) for actual behavior and limits.

The user asked to preserve their research and explore the look, feel and listening journey before building. The selected feature name is **Current**, with a lighter, graphically rich river direction. Soulfire remains the masterbrand in the global header; Current is a feature title with its own smaller river emblem and imagery below that header. The initial entry remains a separate upper-navigation item. Integration into Soulfire's underlying practice model remains undecided.

The working proposition is **personalized listening that people can try and adjust**. Cognitive or mood effects are hypotheses to evaluate, not promised outcomes or treatment claims. The feature name **Current** and lighter river direction are selected. Logo execution, scene examples, detailed layout and engine recommendations remain exploratory. Name/trademark clearance has not been performed.

The later implementation decision authorizes a standalone local prototype, not paid generation services, wearable integration, clinical screening or practice-model integration. Documentation is published separately on `docs/current-experience`; local implementation publication is not authorized. Existing welcome, voice, privacy and care boundaries are preserved.

# Soulfire context

These documents capture the early creative direction for Soulfire. They are working context, not a finalized specification or production agent instructions.

- [Vision](vision.md): the creator's intent and proposed experience.
- [Twelve Steps](twelve-steps.md): the original AA wording supplied by the creator, with space for a broader adaptation.

Keep source teachings, the creator's interpretations, and implementation proposals distinguishable. Preserve uncertainty rather than filling gaps with invented doctrine. No personal user reflections, health information, or credentials belong in these files.

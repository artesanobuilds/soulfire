# soulfire — independent journey design brief

Design critique only. Do not inspect other files, run tools, edit code, access personal context, or delegate. Use only this brief and return an independent proposal in plain text with a compact Mermaid flow. Do not claim to have tested efficacy or users.

Product: a local adult spiritual self-help guide using twelve-step principles for everyday challenges. Not therapy, diagnosis, divine authority or a replacement for professional care. Welcome varied beliefs. No personality labels or compulsory higher-power language. Desired feeling: original, immersive, inviting and serene, with familiar navigation and clear agency. Sage/gold landscapes, gentle motion, optional sound. No guilt streaks, forced step sequence or engagement optimization.

Implemented: optional spoken intro; Play vs Replay based on actual playback; immediate Begin; saved-practice opt-in in browser; neutral returning home; one prompt at a time; steps 1/3/10/11 examples; all twelve shown on map; validated model-generated sort/choose/reflect blocks; private reflection with selected-only AI sharing; optional meditation; next action; pause/back; text, editable dictation and live voice. Dictation shows audio-level waveform only while recording, explicit Stop/transcribe, Discard and failure recovery. Model credentials are server-only. No account or server memory yet.

Requested next: graphically rich generative exercises across all twelve steps; trustworthy durable memory of explicitly shared goals/struggles/preferences; no inferred psychological profile. Constrain model output to validated declarative schemas and trusted components, not generated executable UI. Local SQLite behind a repository interface is under consideration; no hosted service. No silent import of existing reflections. Keep processing consent, saving a practice, and remembering for future personalization separate.

Design these seven journeys:
1. Curious first visitor: optional intro; explore steps without disclosure; preview/start/leave.
2. Something on mind: type/dictate, review, knowingly send to AI, why-this suggestion, accept/adjust/browse.
3. Guided exercise: brief preview and optional sensory settings; one interaction at a time; takeaway; done for today.
4. Unfinished return: neutral resume/new/explore; restore exact scene and authored work, never regenerate on resume.
5. Return after absence: no guilt; private, optional review of outdated memory.
6. Memory: preview explicit memory; remember/edit/not now; visible provenance; pause use/delete; no automatic extraction.
7. Interruption/wrong/too intense/offline: stop media, show what saved, resume/simple local exercise/retry/discard.

State dimensions: intro never/started/completed/skipped; intent; AI processing consent; memory off/on/paused/deleting; exercise preview/active/paused/done/discarded; generation idle/pending/ready/invalid/failed; input typing/recording/processing/review; sensory preferences; feedback wrong/too intense/outdated.

Possible scene families (hypotheses, challenge them): influence/release constellation (1–3); pattern map (4–5); choice path (6–7); repair planning with boundaries (8–9); check-in/optional quiet (10–11); service intentions garden (12). No automatic contact or pressure to reconcile. Do not turn decorative scenes into opaque controls.

Research direction, not efficacy claims: stable outer controls around adaptive content; concise just-in-time explanations; easy correction/dismissal; alternative paths after AI failure; keyboard and reduced-motion equivalence. Optional nature/audio or emotion naming laboratory findings do not establish app therapeutic benefit. Avoid forced breaths/holds and distraction while reading.

Return: (a) strongest coherent journey architecture and Mermaid, (b) three original interaction ideas with accessible alternatives, (c) state/consent mistakes to prevent, (d) most important disagreement with this brief, (e) five observable usability checks. Maximum 1100 words. Do not ask questions; identify assumptions. No implementation edits.

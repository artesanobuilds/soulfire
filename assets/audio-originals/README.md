# Quiet Ember source audio

Two original soulfire ambient candidates generated with Suno v6 and downloaded using its official download workflow on October 22, 2026. The app serves locally prepared AAC loops; originals are retained here for reproduction with `scripts/prepare-ambient-loops.py` from the repository root.

- [Quiet Ember 01](https://suno.com/song/0a26730f-37a2-43bf-bb44-d9e8e0f2fbf8): 179.80 seconds, stereo Opus 48 kHz in an M4A container.
- [Quiet Ember 02](https://suno.com/song/185fb3aa-6470-4be9-917d-0468da251ebd): 179.92 seconds, same format.

Generation direction: warm, spacious zen ambience with soft organic pads, sparse felt piano and muted plucked textures; no requested vocals, percussion, strong beat or dramatic changes. Local preparation crossfades the last and first four seconds into a loop seam. The creator auditioned and liked the music. Automated checks verify decode/play/loop behavior; they are not a subjective musical-quality evaluation.

Private download/account-usage notes remain local and Git-ignored.

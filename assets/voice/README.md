# Welcome narration source

Selected local Kokoro-82M voice `af_heart` via kokoro-onnx, English, synthesis speed 0.84 with deliberate pauses. Duration 23.4465 seconds. No post-synthesis time stretching or voice cloning. The approved script and cue timing are in `public/audio/welcome-introduction.json`.

`prepare-welcome-voice.py` reproduces this WAV and its served AAC version using the already installed local Kokoro tooling. It requires that tooling separately; playback itself needs no model download or credentials. Kokoro model: Apache 2.0; kokoro-onnx inference library: MIT. This is a generic synthetic voice, not a recording of a real identified person.
